# Data Dictionary

This repository uses the schema contract defined in `docs/data-schema.md`.

Canonical identifiers and key fields include:
- `part_number`
- `model`
- `usage_date`, `order_date`, `install_date`, `stock_snapshot_date`
- `usage_qty`, `order_qty`, `fulfilled_qty`, `allocated_qty`
- `minimum_order_qty`, `default_lead_time_days`

For authoritative per-file columns, validation constraints, and examples, use `docs/data-schema.md`.
