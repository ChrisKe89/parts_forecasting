# Dummy input data

Deterministic placeholder datasets for local testing.

- `install_data.csv`: monthly installs totaling **100 machines**.
- `usage_data.csv`: **300** usage records across 30 parts and 10 models.
- `emergency_orders.csv`: **10** emergency order records.
- `cannibalised_parts.csv`: **20** cannibalised part records.
- `part_model_mapping.csv`: 30 parts mapped to models.
- `stock_snapshot.csv`: optional stock snapshot for all parts.
